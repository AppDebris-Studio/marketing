空の奇跡を、みんなで。

虹・雲・朝日・夕陽・雷——あなたが見た空の一瞬を投稿して、 近くにいる人と感動を分かち合うSNSアプリ。

できること

📍

近くの空を発見

位置情報をもとに、今あなたの近くに上がっている虹や夕焼けをリアルタイムで確認できます。

🕰️

72時間の期間限定投稿

投稿は72時間で自動削除。一期一会の出会いだから、今この瞬間が大切。

🍎

Apple でサインイン

メールも名前も不要。Apple ID だけで始められます。位置情報は≈5km単位で匿名化。アカウント削除もアプリ内で完結。

技術的こだわり

🔐

プライバシーファースト設計

緯度経度は±5km単位でファジー化。Exifメタデータは Cloud Functions で自動削除。位置情報の精確な値はサーバー内部にのみ隔離保存。

⚡

スケーラブルな通知設計

Geohash を使った近隣クエリで、ユーザーが増えても全件スキャンせずに近くの人へ通知。FCM Multicast で効率配信。

🌤️

自動天気取得

投稿時の天気・気温は Open-Meteo API でサーバー側が自動取得。ユーザーが入力する手間なし。

🚀

Spec駆動開発

仕様書→実装の順序を厳守するSDD手法で開発。Claude Code + Gemini + Codex の AI トリオで高速実装。
