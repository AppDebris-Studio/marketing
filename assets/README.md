## assets

一番シンプルな「ウェブ画面からアップロード」する手順です。

GitHubで marketing リポジトリを開きます。

画面右上にある [Add file] ボタンをクリック。

[Upload files] を選択します。

アップロードしたい画像（スクリーンショットやロゴなど）を、グレーの枠内にドラッグ＆ドロップします。

一番下の [Commit changes]（保存）ボタンを押します。

💡 CEOの整理術（フォルダを作る方法）
もし「フォルダに分けて整理したい」と思ったら、[Add file] -> [Create new file] を選び、ファイル名の欄に assets/ と入力してください。スラッシュを入れるだけで、勝手にフォルダが作成されます。
